# Remaining behavioral acceptance

Authored rubrics, outside-session review and a maintained status index are delivered
capabilities. They do not imply the following model or participant outcomes. Keep
these follow-ups explicit rather than changing the original roadmap criteria after
work has been accepted.

| Follow-up | Current evidence | What remains |
| --- | --- | --- |
| Reliable routing and answer quality | Four [exploratory cells](../../evals/01-guidance-contribution/observations/2026-09-18.json), one per condition | Broader fixed samples; all eight response-format failures, a tentative preference overstated as settled, and unsupported technical claims remain findings |
| Calibrated automated semantic grading | Independent parent/root agent reviewed all visible outputs under the original rubric | A separate grader tested on independently labelled positive and negative cases; do not call agent review a calibrated grader or human acceptance |
| Paired behavior for 03/04/05/07 and their twins | [Authored observables and critical gates](PAIRED-RUBRIC.md) | Isolated model runs with real authorized tool paths and service readback; a correct request does not prove delegated execution |
| Lesson contribution changes later behavior | Attributed note creation and fresh-session retrieval are accepted; [paired rubric](KNOWLEDGE-RUBRIC.md) is authored | A new session on a different task actually inspects implementation scope before concluding absence; record knowledge reading cost and failing/control cases |
| Decision contribution changes later behavior | Opt-in detector lifecycle, attribution and exact-reference checks are tested | A later reader finds the named fork and applies or challenges its constraint; a classifier verdict alone does not establish this |
| Detector accuracy and semantic duplicate handling | Offline integration tests; historical small author-reported classification runs | Current source-pinned, predeclared positive/negative trials; semantic duplicates remain a documented limit |
| Corrected knowledge is used well | Production operator review preserves the original and a fresh installed session receives the correction | Model use, participant judgement and sustained adoption; retrieval alone is not benefit |
| Human participant adoption | Separate production and onboarding evidence is tracked in the app acceptance ledger | Actual participant use and the specified observation period; fixtures and an authorized operator cannot substitute for participants |

No new paid trials were needed for the September 18 criterion reconciliation. Future
experiments must declare their scenarios, sample, model versions, call cap and scoring
before execution. Keep failures, unavailable outcomes and prior frozen receipts; do
not rerun or change the rubric merely to obtain a passing result.
